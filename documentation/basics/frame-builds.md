# Frame builds

The main frame that we are going to use is **Titania**. Titania offers a high speed (while using her **Razorwing Blitz** augment) that let us cast nuking abilities while on her 4th. We kill enemies by using the Helminth system and incorporating **Thermal Sunder** into our build.

Now, the question that everyone is asking: _**what is the best Titania build?**_

Well, sorry to disappoint you, but there is not a 100% perfect Titania build.&#x20;

Why? Because there are small variables that you can mod on her depending on your likings. Maybe you want to squeeze a bit more range, maybe you want to cap efficiency, etc.

What I will display in here is the build that I currently use and what are the alternatives.

{% hint style="info" %}
There are of course other frames that we can use for mobility, such as Wukong, but we won't focus on them.&#x20;

There are also other abilities that we can use for killing/utility, such as Null Star or Roar. Additional builds for them will also be provided.
{% endhint %}

## Thermal Sunder

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure></div>

* **Aura slot:**
  * **Enemy Radar** makes sure you know where the next batch of enemies are before going into the next room
  * **Corrosive Projection** is very useful on Steel Path fissures to try to squeeze a bit more of damage
* **Exilus slot:**
  * **Primed Sure Footed**. Yes, we know the meme. But honestly, it's the best way to not get ragdolled while flying at high speed and touching walls
  * **Preparation** to make sure you start your missions with full energy (good synergy with **Primed Flow**)

{% hint style="info" %}
If you don't have Primed Sure Footed but wish to gain knockdown immunity, remember that summoning your Archgun gives you 2000 Overguard, which prevents you from knockdowns.
{% endhint %}

* **Ability range:**
  * **Overextended** so Thermal Sunder can hit more enemies in a bigger radius
  * If you prefer more range, you can get it up to 235% or 220% by using **Stretch** or **Augur Reach** respectively.
* **Ability efficiency:**
  * **Fleeting Expertise** so we are almost capped and are able to actually spam Thermal Sunder
  * If you are someone that prefers to be capped, consider using a **rank 4 Fleeting Expertise** + **rank 4 Streamline**
* **Ability duration:**
  * **Primed Continuity** so we counter the negative duration from both Fleeting Expertise and Transient Fortitude
* **Ability strength:**
  * **Transient Fortitude** so we counter the negative strenght from Overextended
  * If you don't want to run this, you can use **Umbral Intensify** instead (you will most likely need more forma or an Umbra Forma though)
* **Utility mods:**
  * **Razorwing Blitz** is mandatory for this build, since it's what allows us to move fast
  * **Archon Vitality** doubles the damage from the heat ticks of Thermal Sunder, while providing a good chunk of health
  * **Primed Flow** so we have more energy to spam more abilities (good synergy with **Preparation**)
* Arcanes:
  * **Arcane Steadfast** is almost mandatory for this build, since it allows us to gain free casts of our Thermal Sunder
  * Last slot is optional, but some options include **Arcane Energize** or **Molt Augmented**
